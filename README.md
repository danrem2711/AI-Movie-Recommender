# AI-Movie-Recommender
This project is an AI-powered Movie Recommendation Web Application developed using Python and Flask. The application uses the TMDB 5000 Movies Dataset together with the TMDB API to provide real-time movie posters, trailers, ratings, and detailed movie information. The recommendation system was built using Scikit-learn with CountVectorizer and Cosine Similarity to generate content-based movie recommendations based on genres and movie descriptions. The frontend was designed using HTML, CSS, and JavaScript with a Netflix-inspired responsive UI that includes autocomplete search, trailer popup modals, genre filtering, and match percentage scoring. SQLite was integrated as the local database system to implement the favorites and watchlist functionality. The project was deployed online using Render, allowing the web application to be accessed publicly through a live URL. Throughout this project, technologies and tools used include Flask, Pandas, Requests, Scikit-learn, SQLite, TMDB API, HTML/CSS/JavaScript, GitHub, and Render for deployment.
